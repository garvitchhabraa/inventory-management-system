# Inventory Management System

A full-stack Inventory Management System built using **HTML, CSS, JavaScript, Node.js, Express, and MySQL**.

---

## ✨ Features

- Add new products
- Edit existing products
- Delete products
- Search products
- Dashboard statistics
- Low stock indicators
- Responsive design
- MySQL database integration

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MySQL

### Tools

- VS Code
- Git
- GitHub

## 🚀 How to Run the Project

### 1️⃣ Start Backend

Open terminal:

```bash
cd backend
npm install
node server.js
```

Server will run on:

```
http://localhost:5000
```

---

### 2️⃣ Open Frontend

Open `frontend/dashboard.html` using **Live Server** in VS Code.
